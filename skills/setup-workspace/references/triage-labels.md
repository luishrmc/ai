# Triage Labels

Engineering and shaping skills use five canonical triage roles. This table maps those canonical roles to the label strings configured in this repository's issue tracker.

| Canonical Role | Tracker Label | Meaning |
| :--- | :--- | :--- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on reporter or stakeholder for clarification |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for autonomous agent execution |
| `ready-for-human` | `ready-for-human` | Requires human judgment, credentials, or manual execution |
| `wontfix` | `wontfix` | Out of scope or will not be actioned |

When a skill instructs you to apply a canonical triage role (such as `ready-for-agent`), apply the corresponding `Tracker Label` string from the table above.
